## Editing

- Pages are generated by `_src/build.py` from `_src/shell.py`, `_src/hospital.py` and `_src/printing.py`. To rebuild, run `python3 -I _src/build.py <v6 folder> <out folder>`.
- Small text fixes can be made straight in the HTML. Re-running the build overwrites them, so copy the fix into `_src` too.
- **Domain switch at cutover:** change `SITE` in `_src/shell.py` (for example to `https://plasticsunique.com.au`) and rebuild. Canonicals, sitemap and schema all follow.
- `/_src/` is blocked from public view by a rule in `netlify.toml`.
